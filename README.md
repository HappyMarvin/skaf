# Вилета 6 — по шагам

Статическое руководство для конкретного шкафа **120 × 40 × 210 см**, с шестью фасадами и без ящиков. Включает 13 этапов, собственные SVG-схемы, поиск деталей и локальное сохранение прогресса.

Сайт находится в `docs/`. Его можно открыть через `docs/index.html` без сервера и интернета. Для переноса копируйте папку целиком: PDF производителя, шрифт Golos Text и лицензия уже внутри. Подробности для сборщика и фабрики — в `docs/README.txt`.

## Локальный просмотр

Нужен Node.js 20 или новее. Сборка сайта не требуется.

```sh
npm ci
npm run serve
```

Откройте [локальный сайт](http://127.0.0.1:4174/skaf/). Префикс `/skaf/` повторяет адрес проекта на GitHub Pages.

## Проверки и схемы

```sh
npx playwright install chromium
npm test
npm run diagrams:check
```

Тесты запускают свой локальный сервер и проверяют существующие сценарии сборки, поиск, сохранение, клавиатуру, мобильную вёрстку и offline-режим. Результаты и скриншоты остаются в игнорируемой папке `work/`. При необходимости можно использовать установленный Chromium через переменную `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

`docs/diagrams.js` содержит исходник схем этапов. `npm run diagrams` обновляет самостоятельные SVG в `docs/assets/` и создаёт превью в `work/diagrams/`. Генератор проверяет известные номера деталей и отсутствие растровых изображений. Обложки создаются командой `npm run heroes` (нужен Python 3, дополнительных Python-пакетов нет). После перерисовки проверьте результат визуально.

## GitHub Pages

После отправки `main` выберите в настройках репозитория **Pages → Deploy from a branch → main → /docs**. Файл `docs/.nojekyll` отключает обработку Jekyll. Публикуется только содержимое `docs/`; зависимости, тесты и генераторы на сайт не попадают.

Адрес проекта: [happymarvin.github.io/skaf/](https://happymarvin.github.io/skaf/). Ссылки на ресурсы относительные, маршруты шагов используют hash. Серверного кода и аналитики нет.
