ВИЛЕТА 6 — ПОШАГОВОЕ РУКОВОДСТВО

Для конкретного комплекта 120 × 40 × 210 см: три большие и три малые
двери, без ящиков и направляющих. Руководство содержит 13 этапов.

КАК ОТКРЫТЬ
1. Распакуйте архив целиком, сохранив папку assets рядом с index.html.
2. Откройте index.html в современном браузере. Сервер и интернет не нужны.
3. На схеме выберите номер детали: появятся название, размеры и количество.
   Схему можно увеличить. В каталоге есть поиск по имени, размеру и №8.

ПРОГРЕСС
Отметки этапов, найденных деталей и текущий шаг сохраняются локально
в этом браузере. Они не передаются на сервер и не синхронизируются
с другими устройствами. Очистка данных браузера может удалить отметки.
Сброс доступен через «Помощь». Просмотр будущего этапа не завершает его.

ИСХОДНАЯ ИНСТРУКЦИЯ
PDF производителя приложен в assets/manufacturer.pdf и доступен кнопкой
«Исходная инструкция». Внешние ссылки в «Об инструкции» требуют интернета;
доступность официальных страниц со временем может измениться.
Все основные схемы сайта нарисованы заново в SVG. Фотографии и растровые
кропы исходных схем в сайт не включены. Локальный шрифт Golos Text
распространяется по лицензии SIL OFL; текст лицензии в assets/fonts/OFL.txt.

ФАБРИКЕ ДЛЯ ПРОВЕРКИ
Это адаптация данных комплекта, а не заводская сертификация сборки.
Просим подтвердить ориентацию одинаковых по размеру панелей по сверлению,
распределение крепежа по узлам и установку стенного крепления/толкателей.
В исходных данных остаются неясности: длина штанги, противоречивый размер
соединительного профиля и количество заглушек эксцентриков (8 или 10).
Общие количества фурнитуры в каталоге не являются расходом на каждый шаг.
Схемы не задают координаты новых отверстий и не служат шаблоном сверления.
